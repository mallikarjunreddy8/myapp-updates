# Amrita BTech app — install on Android

For Amrita Bengaluru B.Tech students: attendance, marks, timetable, exams, calendar, gate pass and class alarms in one app.

## Install (first time)

1. **Download:** [Amrita-BTech-Classmates.apk](https://github.com/mallikarjunreddy8/myapp-updates/raw/main/Amrita-BTech-Classmates.apk) (about 22 MB).
2. Open the downloaded file. If Android asks, allow **Install unknown apps** for your browser / WhatsApp / Files.
3. If **Play Protect** shows a warning, tap **More details → Install anyway**. (It warns about any app that is not from the Play Store.)
4. Open the app and follow the welcome steps (your register number, branch, section).

## Updates

You don't need to download the APK again. The app checks this page by itself and shows
**"App update ready → Restart"** (about 0.5 MB). You can also tap **Settings → About → Check now**.

## Privacy

- Your marks, attendance and passwords stay on your phone. Nothing about you is stored here.
- Update packs are signed; the app refuses any pack that is not signed by the maker.
- The app asks once whether you're OK to tell the maker you installed it (name, roll number, section). You can say no.
